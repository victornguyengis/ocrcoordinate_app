# ocrcoordinate_app
An app to help converting coordinate table (VN2000) from image to dxf.
Copyright © 2026 Victor Nguyen.
## Giới thiệu
ocrcoordinate_app là ứng dụng được xây dựng trên nền tảng Streamlit, sử dụng các thư viện OCR mã nguồn mở của Python để nhận dạng và xử lý tọa độ VN2000 từ hình ảnh, sau đó chuyển đổi dữ liệu thành tệp DXF.

Ứng dụng được phát triển với mục đích tham khảo, học tập và giải trí.
